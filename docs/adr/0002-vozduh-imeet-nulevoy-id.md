# 0002. Воздух всегда имеет числовой ID 0

Дата: 2026-10-28
Статус: принято

## Контекст

По [ADR 0001](0001-chislovye-id-pri-zamorozke.md) числовые ID выдаются по возрастанию
текстового ID. Из этого следует, что `base:air` получит ноль только случайно: мод с
пространством имён `aaa` отодвинет его на единицу.

При этом воздух нужен в трёх горячих местах:

- `Section::default()` — новая секция заполнена воздухом, и это самое частое состояние.
- Счётчик `non_air` в секции — по нему мешинг пропускает пустые секции целиком.
- Проверка «рисовать ли грань» в мешере — миллионы раз на кадр при радиусе 12.

Если ID воздуха не константа, то либо секция хранит его копию (лишние 2 байта на секцию
и риск рассогласования), либо каждый вызов `get`/`set` принимает ID воздуха параметром,
либо воздух ищется в реестре по строке.

## Решение

`BlockId::AIR` — константа, равная нулю. `BlockRegistry::freeze` после сортировки
переносит воздух в нулевую позицию, а блок, оказавшийся нулевым, занимает освободившееся
место. Остальные ID сохраняют позиции, выданные сортировкой.

Регистрация `base:air` обязательна: без неё заморозка возвращает ошибку
`MissingAir`, а не подставляет воздух молча.

## Следствия

- `Section::default()`, `non_air` и проверки прозрачности работают с константой,
  без обращения к реестру и без лишнего поля в секции.
- Свойство из ADR 0001 — «ID не зависят от порядка установки плагинов» — сохраняется:
  перестановка воздуха детерминирована и не зависит от порядка регистрации.
- `Blocks::id` и `Blocks::identifier` обязаны учитывать перестановку. Это сделано
  в `Blocks::remap`, и на согласованность есть тест: для каждого блока проверяется,
  что перевод числового ID в текстовый и обратно даёт исходное значение.
- Воздух нельзя переопределить модом: `base:air` занят. Это сознательное ограничение —
  «пустота» не должна быть предметом переопределения.

## Альтернативы

**Хранить ID воздуха в секции.** Отвергнуто: 2 байта на каждую из ~15 000 секций — мелочь,
а вот риск рассогласования между секциями, созданными до и после перезагрузки реестра,
не мелочь.

**Передавать ID воздуха параметром в `get`/`set`.** Отвергнуто: засоряет самый горячий
API движка и переносит ответственность на каждого вызывающего.

**Зарезервировать диапазон служебных ID до сортировки.** Отвергнуто как преждевременное:
воздух — единственный блок, который нужен движку по имени. Если понадобятся другие
(например, заглушка для блоков удалённого мода), решение расширится до резерва.
